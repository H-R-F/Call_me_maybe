How it all fits together

This program implements a constrained decoding pipeline for LLM function calling. It loads function definitions and prompts from JSON, initializes Qwen3-0.6B, then for each prompt it selects the correct function name using token-trie-constrained decoding (no hallucination — only valid function names can be generated) and extracts typed parameters from the prompt via regex.

The key innovation: function name selection is guaranteed to return a valid function because the token trie physically prevents the model from generating any token sequence that doesn't match a known function name.

1. CLI & Entry Point

def _build_parser() -> ArgumentParser: parser = ArgumentParser(description="Call Me Maybe") parser.add_argument("--functions_definition", default="data/input/functions_definition.json") parser.add_argument("--input", default="data/input/function_calling_tests.json") parser.add_argument("--output", default="data/output/function_calling_results.json") return parser

--outputdata/output/function_calling_results.jsonResults output path

main() function

def main(argv: Sequence[str] | None = None) -> int: parser = _build_parser() args = parser.parse_args(argv) try: run_pipeline( functions_definition_path=args.functions_definition, input_path=args.input, output_path=args.output, ) except Exception as exc: print(f"Error: {exc}", file=sys.stderr) return 1 return 0

Key details:

  • If run_pipeline() raises any exception, it's caught, printed to stderr, and the process exits with code 1
  • Success returns 0
  • Sequence[str] | None type hint allows injecting test args

2. Load Data

src/io_utils.py handles all file I/O. It reads JSON from disk and validates it through Pydantic models.

load_json_file() — Low-level reader

def load_json_file(path: str) -> Any: file_path = Path(path) raw_text = file_path.read_text(encoding="utf-8") return json.loads(raw_text)

Raises FileNotFoundError if file doesn't exist, ValueError if JSON is malformed.

_validate_model() — Pydantic validator

def _validate_model(model_type: type[ModelT], data: Any) -> ModelT: validator = getattr(model_type, "model_validate", None) if callable(validator): return validator(data) # Pydantic v2 return model_type.parse_obj(data) # Pydantic v1 fallback

Compatible with both Pydantic v1 and v2.

Schema models (src/schema.py)

class ParameterSpec(BaseModel): type: Literal["string", "number", "integer", "boolean", "object", "array"] class FunctionDefinition(BaseModel): name: str description: str parameters: dict[str, ParameterSpec] returns: ParameterSpec class PromptItem(BaseModel): prompt: str = Field(min_length=1) class OutputItem(BaseModel): prompt: str name: str parameters: dict[str, Any]

Load functions

def load_function_definitions(path: str) -> list[FunctionDefinition]: data = load_json_file(path) if not isinstance(data, list): raise ValueError(f"{path!r} must contain a JSON array") return [_validate_model(FunctionDefinition, item) for item in data] def load_prompts(path: str) -> list[PromptItem]: data = load_json_file(path) if not isinstance(data, list): raise ValueError(f"{path!r} must contain a JSON array") return [_validate_model(PromptItem, item) for item in data]

Both validate the JSON is an array, then validate each item against the Pydantic model.

3. Init Model

llm_sdk/llm_sdk/__init__.py wraps HuggingFace transformers for local inference.

Constructor

def __init__( self, model_name: str = "Qwen/Qwen3-0.6B", device: str | None = None, dtype: torch.dtype | None = None, ):

Device auto-detection

if device is None: if torch.backends.mps.is_available(): # macOS Metal → MPS device = "mps" elif torch.cuda.is_available(): # NVIDIA GPU → CUDA device = "cuda" else: device = "cpu" # Fallback → CPU

Priority: MPS (Apple Silicon) → CUDA (NVIDIA) → CPU.

Dtype selection

if dtype is None: dtype = torch.float16 if self._device in ["cuda", "mps"] else torch.float32

float16 on GPU to save memory, float32 on CPU for compatibility.

Model loading

self._tokenizer = AutoTokenizer.from_pretrained(model_name, ...) if self._tokenizer.pad_token_id is None: self._tokenizer.pad_token_id = self._tokenizer.eos_token_id self._model = AutoModelForCausalLM.from_pretrained( model_name, torch_dtype=self._dtype, device_map="auto" if device == "cuda" else None, ) self._model.to(self._device) self._model.eval() for p in self._model.parameters(): p.requires_grad = False

Disables gradients and sets eval mode — this is inference-only.

Three key methods

MethodSignatureWhat it does
encode() encode(text: str) → Tensor Tokenizes text, returns 2-D input_ids tensor on device
decode() decode(ids) → str Converts token IDs back to text, skips special tokens
get_logits_from_input_ids() get_logits_from_input_ids(ids) → list[float] Forward pass on input IDs, returns logits for the last token only — raw (no softmax)

4. Decode Loop

This is the core of the program. For each prompt, decoder.decode() performs two phases: function name selection and parameter extraction.

def run_pipeline(**kwargs): functions = load_function_definitions(fn_path) # list[FunctionDefinition] prompts = load_prompts(input_path) # list[PromptItem] model = Small_LLM_Model() # Qwen3-0.6B for item in prompts: decoded = decode(model=model, prompt=item.prompt, functions=functions) outputs.append(OutputItem( prompt=item.prompt, name=decoded["name"], parameters=decoded["parameters"], )) write_output(output_path, outputs)

4a. Select function name (decoder.py)

Step 1 — Build context prompt

context = [ "You are a function selector.", f"User request: {prompt}", "Available functions:", ] for fn in functions: context.append( f"- name: {fn.name}; description: {fn.description}; " f"parameters: {', '.join(fn.parameters.keys())}" ) context.append("Return only the function name.") prompt_text = "\n".join(context) + "\nAnswer: "

Tells the LLM: "here are the available functions, return the right name for this user request".

Step 2 — Build token trie

def _build_token_trie(functions, model): root = TrieNode() mapping = {} for fn in functions: token_ids = model.encode(fn.name) # tokenize function name token_ids = tuple(_tensor_to_ids(token_ids)) # flatten to list[int] mapping[token_ids] = fn.name # reverse lookup node = root for token_id in token_ids: node = node.children.setdefault(token_id, TrieNode()) node.terminal = True return root, mapping

TrieNode dataclass:

class TrieNode: children: dict[int, "TrieNode"] # token_id → next node terminal: bool # True if this node ends a valid name

Example: for functions fn_greet, fn_add, the trie maps token sequences to names. At each step, only tokens present as children in the trie are valid choices.

Step 3 — Walk the trie (constrained decoding)

node = root generated_ids = [] while node.children: # until leaf reached logits = model.get_logits_from_input_ids( prompt_ids + generated_ids) # full context so far allowed = list(node.children.keys()) # ONLY valid next tokens next_id = _select_max_logit(logits, allowed) # highest logit among allowed generated_ids.append(next_id) node = node.children[next_id] if node.terminal and not node.children: # reached end of a name break name = mapping.get(tuple(generated_ids)) # look up function name

This is the key trick: instead of letting the LLM generate freely (which could output "fn_unknown" or garbage), we physically restrict the output vocabulary at each step to only the tokens that lead to a valid function name. The LLM still gets to score the options via logits, but it can't hallucinate an invalid name.

def _select_max_logit(logits, allowed): best_id, best_score = -1, -inf for token_id in allowed: score = logits[token_id] if score > best_score: best_score, best_id = score, token_id return best_id

4b. Extract parameters

_generate_parameters() is a deterministic regex-based extractor — no LLM calls needed.

Extract numbers:

numbers = [float(x) for x in re.findall(r"-?\d+(?:\.\d+)?", prompt)]

Finds all integers and decimals in the prompt (e.g., "add 42 and 7" → [42.0, 7.0]).

Extract quoted strings:

quoted_strings = re.findall(r"['\"]([^'\"]+)['\"]", prompt)

Finds content inside single or double quotes.

Extract booleans:

if "true" in lowered and "false" not in lowered: params[name] = True elif "false" in lowered: params[name] = False

Special handler — fn_greet:

match = re.search(r"\bgreet\s+([A-Za-z]+)", prompt, re.I) if match: return match.group(1)

Extracts the name after "greet" (e.g., "greet John" → "John").

Special handler — fn_substitute_string_with_regex:

# Extracts source_string, regex, replacement from prompts like: # 'replace all "hello" with "hi" in "hello world"' source = re.search(r'\bin\s+"([^"]+)"', prompt, re.I) # "hello world" replacement = re.search(r'\bwith\s+["\']?([^"\']+)["\']?', prompt) # "hi" regex = re.search(r'\bword\s+["\']([^"\']+)["\']', prompt) # "hello"

Parameter assignment logic: iterates through function_def.parameters in order and assigns extracted values by index. Numbers are assigned to numeric params in order, strings to string params in order, etc.

5. Write Output

src/io_utils.py → write_output()

def write_output(path: str, items: Iterable[OutputItem]) -> None: file_path = Path(path) file_path.parent.mkdir(parents=True, exist_ok=True) payload = [item.model_dump() for item in items] content = json.dumps(payload, ensure_ascii=False, indent=2) file_path.write_text(content, encoding="utf-8")

What happens:

  • Creates the output directory if it doesn't exist (data/output/)
  • Each OutputItem is serialized via model_dump() (Pydantic) → {"prompt": "...", "name": "fn_greet", "parameters": {"name": "John"}}
  • Written as pretty-printed JSON with 2-space indentation
  • ensure_ascii=False preserves Unicode characters
